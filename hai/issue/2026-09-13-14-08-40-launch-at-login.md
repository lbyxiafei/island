## 背景

`island` 是常驻工具：没有进程在跑时，global hotkey 静默失效。而现在**没有任何自动拉起机制**，每次重启电脑、或进程被结束后，都必须手动执行：

```bash
cd ~/Repos/island && nohup ./build/Island.app/Contents/MacOS/Island >/tmp/island.log 2>&1 &
```

2026-09-13 人工验收时踩到：实例被结束后，用户按快捷键毫无反应且无从察觉。

## 期望结果

- 支持「开机 / 登录时自动启动」，并且这个开关能在菜单栏 status item 里看到状态、随时切换
- 卸载干净：关掉即从系统登录项里消失，不留残留
- 副作用要可控且可解释：用户应当能在「系统设置 → 通用 → 登录项」里自行关掉

## 备注

- 首选方案 `SMAppService.mainApp`（macOS 13+，`ServiceManagement` 框架）：由 app 自己注册/注销，无需手写 LaunchAgent plist，用户在系统设置里看得见。风险是它通常要求 app 位于稳定路径（建议 `/Applications`），且对签名有要求——本 app 目前只是 **ad-hoc 签名**，是否可用需要实测
- 备选方案：写 `~/Library/LaunchAgents/<bundle-id>.plist` + `launchctl bootstrap gui/$UID`。不依赖签名，但由脚本维护，卸载需要显式 `bootout`
- 实测结论（含是否被 ad-hoc 签名卡住）记录在本 issue 正文

## 实测结论（2026-09-13）

**`SMAppService.mainApp` 在 ad-hoc 签名 + 非 `/Applications` 路径下可用**，不需要付费开发者账号，也不需要手写 LaunchAgent plist。因此不采用备选的 `~/Library/LaunchAgents` 方案。

- 注册：`island --login-item-enable` → `status: enabled`
- 注销：`island --login-item-disable` → `status: notRegistered`
- 往返可重复：`enabled → notRegistered → enabled`
- 重新构建 `.app`（同一路径）后状态仍为 `enabled`，不会被重建打断
- 系统侧证据，`sfltool dumpbtm`：

  ```
  Name: island
  Type: app (0x2)
  Flags: [  ] (0)
  Disposition: [enabled, allowed, notified] (0xb)
  Identifier: 2.com.binyanli.island.poc
  URL: file:///Users/binyanli/Repos/island/build/Island.app/
  Bundle Identifier: com.binyanli.island.poc
  ```

### 已知限制（照实记录）

1. **`unregister()` 不会删除 BTM 记录，只把它标成 disabled**：注销后 `status` 正确返回 `notRegistered`，但 `sfltool dumpbtm` 里记录仍在，`Disposition: [disabled, allowed, notified]`。系统设置 → 通用 → 登录项 里是否还能看到这一条，未经人工确认
2. **登录项指向的是 `~/Repos/island/build/Island.app`**（构建目录）。稳定使用建议把 app 拷到 `/Applications` 后重新注册；bundle 被移动后状态可能变成 `notFound`，此时菜单会提示"move Island.app to /Applications"
3. 在从未注册过的机器上，首次查询返回的是 `notFound` 而不是 `notRegistered`（macOS 行为）；两者在菜单里都表现为未勾选，不影响使用
4. **未验证"下次登录真的会自启"**：这需要注销/重启，属于人工验收项

## 命令行接口（同时用于自动化验证）

```bash
./build/Island.app/Contents/MacOS/Island --login-item-status
./build/Island.app/Contents/MacOS/Island --login-item-enable
./build/Island.app/Contents/MacOS/Island --login-item-disable
```

注意：这三个 flag 必须用 `.app` 包内的可执行文件调用（`SMAppService.mainApp` 依赖 main bundle 的身份）。
