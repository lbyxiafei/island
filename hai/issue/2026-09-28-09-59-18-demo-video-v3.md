## 背景

v2 介绍视频是实录（两个普通 Terminal 窗口 + CI / token 之类的任务），用户反馈不符合要求：画面和他真实的用法（tmux 左 Claude Code、右 pi）对不上，任务内容看不懂，全是终端没有 VS Code 和 Codex，分辨率也不够。用户要求大胆模拟、画面清晰、分辨率尽量高；另外问能不能把安装命令简化成 `brew install island`。

## 期望结果

- 4K 60 秒介绍视频，场景还原真实环境：Ghostty + tmux 分屏（Claude Code / pi）、VS Code 集成终端里的 Claude Code、Codex 桌面版；任务是天气、HN 新闻、东京行程、单元测试这类人人看得懂的
- README GIF 从新视频里截
- 安装命令去掉 `--cask`；`brew install island` 需要进官方 homebrew/cask（≥ 75 star 门槛），写进发布文案

## 备注

- 全程在独立 worktree（`../.worktree/<repo>-<slug>`）中完成，合回 master 前 `make verify` 全过，流程见 AGENTS.md / Workflow / Worktree 与 Ship
