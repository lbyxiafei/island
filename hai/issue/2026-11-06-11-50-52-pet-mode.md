## 背景

2026-11-06 用户需求原话：加一个"宠物模式"——一直有一个 show on top 的悬浮窗，每次 agent 结束宠物 pop up 出 title，点击 title 即跳转；宠物可定制、半透明 / 透明（agent 结束时变半透明），可拖动。形象"icon/动物/avatar 可爱形象都行"，可以稍微动一动；跑完时旁边多出对话框，不点就一直在，新的继续出现；**多了怎么排版、要不要隐藏交给 Agent 设计，后期再打磨**。

PLAN 没有这一项，属于用户明确指令覆盖 scope；PLAN 未改。

## 设计（Agent 自定，后期可调）

- 开关：菜单栏 `Pet mode` 勾选项 + Settings → Pet；**默认关**
- 宠物：64×64 无边框面板，`.floating` 层级、所有 Space、不抢焦点；可拖动，位置记忆；显示器拔掉 / 位置出屏时回到主屏右下角
- 形象：内置 7 个 emoji 角色（猫 / 狗 / 狐狸 / 企鹅 / 鲸 / 机器人 / 幽灵），或选一张自己的图片
- 透明度：空闲透明度可调 0–100%（默认 40%，0 = 完全看不见）；有未读或鼠标悬停时 100%。用户原话里"agent 结束半透明"理解为"结束时变得更显眼"，所以取 100%；如果想要的是半透明，再调
- 动效：空闲轻微上下浮动，有新 run 完成时跳一下；可关
- 气泡：每个未读 run 一个，**最多 3 个，最新的贴着宠物**，其余折叠为 "+N more"（点开完整列表）；气泡在宠物靠屏幕中间的一侧展开，宠物在下半屏往上长、上半屏往下长，始终不出屏。点击 = 跳转 + 已读；× = 已读不跳转；气泡不会自动消失
- 宠物右上角红色角标 = 未读数；单击宠物 = 开 / 关任务列表；右键 = 显示列表 / 全部忽略 / 宠物设置 / 关闭宠物模式
- 宠物开着时，顶部悬浮窗不再自动弹出（避免同一个 run 两处提醒）；热键 / 菜单召唤不变

## 期望结果

上述行为在真机可用；纯逻辑（`IslandCore/Pet.swift`）有单测，AppKit 部分（`PetController` / `PetSettingsView`）登记为 UI 排除项。
